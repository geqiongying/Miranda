# 录像逻辑复核（防「只看局部」）

复核方式：8 段视频全覆盖关键帧抽样 + 板书逐字核对 + 与引擎代码对照。

## 已确认成立（板书/口播一致）

1. **通用大周期分时四条**（147 画面）：三连阳10%/倍量前五 → 最大量阳线 → 实体新高+缩半启动 → 破位/放量阴破高  
2. **3倍量建仓分强弱**（147 板书「3倍量 建仓」）  
   - 强建：收盘/幅度新高 → **可直接缩量一半低吸**  
   - 弱建：不破位但不新高 → **缩量一半后等放量突破**（不是「随便站上就买」）  
3. **爆量大阳洗盘**：长洗缩至分歧量 1/2 下再站上；短洗不可击穿分歧最低点；挖坑约 1/4 地量再站回  
4. **大阴反包后**（a5ca 板书核对）：  
   - 「反包 加速」：拉升中放量大阴 → 连续两根中阳反包 → 量不缩到最高量 **1/3** 以下  
   - 「反包 长洗做深V」（不是「长线做稳V」）→ 反包筑箱 → 缩量1/2 → 再缩到最高量1/4  
5. **强控盘**（147 板书「资金强势特征」）：**拉升中量最小** + 实体新高确立 + 缩量回踩 —— 与「爆量启动」是**另一套**逻辑  

## 此前整理的偏差（已纠正）

| 问题 | 原因 | 纠正 |
|------|------|------|
| 把多套路揉进一个「买点 V」 | 典型 AI 合并过度 | 拆开：量能回踩 V / 强控盘 Ctl / 横盘 H |
| 弱建写成「先站上再缩半」 | 口播摘要不精确 | 按板书改为「缩半后放量突破」 |
| 「长线做稳V」 | 板书误读 | 实为「长洗做深V」 |
| 买点 V 用 `structureOk` 滥竽充数 | 条件过宽 | 去掉单靠结构凑分 |
| 同一天既要 3 倍量又要 1/4 地量 | 忽略时序 | 启动与洗盘分阶段判断 |
| 引擎几乎没写「拉升缩量强控盘」 | 漏看板书 | 新增买点 Ctl |

## 多套路之间并不矛盾

- **爆量/3倍量**：分歧大，先换手，再缩量确认  
- **强控盘**：抛压极轻，拉升量可以很小  
- **首板翻倍量**：潜伏点火要再异动  

不能合成「只要放量就好」或「只要缩量就好」。选股/问答必须先判断在哪一套剧本里。

## 引擎仍做不到、必须人工看的

- 分时「右空」、分时最低点放量测试  
- 「1 个月同区间 ≥2 次涨停」精确统计（可后补）  
- N 型左侧高点平台量是否被盖过的完整结构标注  
- 短洗「支撑画在前波顶还是底」的强弱自动判别（目前只给提示）  

这些留在笔记里，问答结论会标明「需人工确认」。
