## 1. 通用大周期分时（板书四条）

1. 三连阳累计约 10%，或倍量过前五  
2. 找到放量最大阳线（成本锚）  
3. 实体创新高 + 缩量约一半 → 回踩成本下沿/半位启动  
4. 破位 / 放量阴破高 / 放量滞涨 → 失效或先走  

## 2. 爆量大阳线 / 3倍量建仓（板书核对）

- 找抢筹/分歧量：约 **3 倍量且过前五**  
- **强建仓**（收盘/幅度新高）：可 **直接缩量一半低吸**  
- **弱建仓**（不破位但不新高）：**缩量一半后，再等放量突破**（板书原句，不是「先站上就买」）  
- **长洗**：缩到分歧量 **1/2 以下**，再 **站上**分歧实体 → 上车  
- **短洗**：缩量但仍可能 >1/2；**不可击穿分歧最低点**；站上短洗实体  
- **挖坑**：跌破建仓区，但持续约 **1/4 地量**，再 **站回**分歧量之上  
- **右空**：分时急跌后持续缩量横盘 → 恐慌已尽，不必恐慌割  

### 2b. 资金强势特征（强控盘，另一套）

板书：`拉升中量最小` → `实体新高确立` → `缩量回踩`  
与爆量换手剧本不同：这里看重抛压轻，不能和「必须天量」混用。
## 3. 低位首板潜伏

1. 启动前 **地量**（跌无可跌）  
2. **堆量**拿货：连续放量且价格连续向上；上影不宜过长（勿超当日一半）  
3. 回调缩回 **地量附近**，且价格到前期 **放量大阳底部**  
4. 量能再次 **翻倍** → 潜伏买点（博弈首板）  

## 4. 扫货加震仓找启动

1. 先有拿货痕迹（脉冲+横盘交换筹码）  
2. 回调见 **地量 ≈ 上涨量 1/4**  
3. **破位**放量释放恐慌  
4. 次日 **阳线反包** 或 **金针**（下影 ≥ 实体 2 倍）  
5. 再震仓回踩并打穿成本区 → **直接上车**  
- 震仓时：反弹量应小于下跌量；起涨后涨停宜偏缩量（抛压已尽）  

## 5. 大阴线洗盘（反包后）— 板书原文

前置：超跌语境常见；**大阴后须反包，禁止直接抄大阴**。

**反包 加速**（板书）：
1. 拉升当中出现放量大阴线  
2. 连续两根中阳线反包  
3. 量不缩小到最高量 **三分之一**  

**反包 长洗做深V**（板书原文，不是「长线做稳V」）：
1. 出现放量大阴线  
2. 反包构筑箱体平台  
3. 缩量 1/2  
4. 缩量到最高量 1/4  

**短洗画线**：
- 强反包（放量/堆量）：支撑偏前波 **顶部**  
- 弱反包：支撑偏前波 **底部/最低点**  
- 上车多在反包后的 **缩半回踩确认**，不是反包瞬间无脑追  

## 6. 强势建仓（短线打引）

- 选股：约 **1 个月内 ≥2 次涨停**，且在 **同一价格区间**  
- 两连板后大阴，修复阳线量 **不得超过** 大阴量  
- 再出放量「壮阳」超前期量 → 缩量回踩至调整低量区 = **B 点**  
- **无连板预期兑现 → 及时卖出**（短线不做长）  

## 7. 横盘起爆

1. 前有强势进场（如连阳+明显放量）  
2. 横盘 **不深调**；区间内反复 **涨放、回调缩**  
3. 洗盘结束常在 **MA20** 附近  
4. 向下试探 K：下影 ≥ 整根 K 一半；分时 **最低点明显放量**（测试盘口）→ 加入观察/准备上车  
- 向上试探的量 **不能比主升阶段大太多**（防出货）  

## 8. N 型提醒

- 单看 N 不够；要低位放量盖过左侧高点平台量；单阳不破  
- 高位无套牢却放量（尤其放量阴）→ 回避
