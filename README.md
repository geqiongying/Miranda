# MIRANDA · 双入口学习站

Miranda 的私人 A 股学习站：**均线手记** 与 **量能操盘台** 分轨运行，模板与闸门互不混用。

线上地址（合并 `main` 并由 GitHub Pages 发布后）：

`https://geqiongying.github.io/Miranda/`

## 双入口

| 入口 | 页面 | 逻辑 |
|------|------|------|
| 首页门户 | `index.html` | 选择进入哪条线 |
| 均线手记 | `ma.html` | 买点 A/B/C、卖点 A/B；`data-engine="ma"` |
| 量能操盘台 | `coach.html` | 买点 V/Ctl/H、卖点 V；`data-engine="volume"` |

## 量能全市场扫描

操盘台「开始全市场扫描」会：

1. 拉取东财列表：沪市主板 + 深市主板 + 创业板 + 科创板（排除 ST / 新股 C 等）
2. 按量价（开市）或市值分层（休市）粗筛
3. 对精评数量（40 / 60 / 100）做量能模板打分并推荐

不是只扫你问过的代码。

## 重要说明

- 页面显示的是 **规则契合度**，不是胜率
- **不承诺、也不暗示 90% 成功率**
- 仅供个人学习参考，不构成投资建议
