# MIRANDA · 均线手记

Miranda 的私人学习站点：把多周期均线（5-20-99-128-225）、箱体、做 T 与仓位楼层整理成可随时翻阅的个人网址，并附带简易分析台。

## 本地预览

```bash
python3 -m http.server 4173
```

浏览器打开：http://localhost:4173

## 发布成只属于你的网址（GitHub Pages）

1. 合并本仓库到 `main`
2. 打开 GitHub 仓库 → **Settings** → **Pages**
3. Source 选择 **GitHub Actions**（本仓库已附带工作流）
4. 发布后地址一般为：

`https://geqiongying.github.io/Miranda/`

也可在 Pages 设置里绑定自己的自定义域名。
