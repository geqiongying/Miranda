03 / Rules

当前使用的教学规则

均线模板 + 已精读的录像量能篇（Release Videos-Laoyao）。其余视频继续上传后会再加深。

录像精读 · 通用大周期分时

  1. 三连阳累计约 10%，或倍量过前五 —— 确认启动
  2. 找到放量最大阳线 —— 锚定成本区
  3. 实体创新高 + 缩量约一半 —— 回踩成本下沿/半位再启动
  4. 破位 / 放量阴破高 / 放量滞涨 —— 失效或先走

另含：3倍量试盘/建仓、分歧转一致、超跌超量后禁止直接抄大阴、须等反包；N 型必须看低位放量是否盖过左侧套牢量。老师说的「10%→90%」是强调「图形+量能位置」，不是网站胜率承诺。

买入闸门

  • 假突破 / 偏空结构 / 放量滞涨 → 不建议买
  • 贴着长期压力、卖点更强、买点未齐 → 暂不买
  • 买点 A/B/C/V 匹配充分 → 可小仓试错或分批关注

仓位心法

  • 空仓：触发位未到就不动
  • 轻仓：压力先做 T / 分批
  • 重仓：信号转弱先减负，不摊成本硬扛
买点 A

强势回踩

趋势未坏 + 缩量回踩关键均线 + 止损清楚。第一笔只做计划仓 30%–40%。

买点 B

收敛变盘

99/128/225 靠近、波动变窄。小仓试错，跌破收敛下沿认错。

买点 C

突破回踩确认

突破后不急追；等回踩原压力不破再介入。

买点 V

录像量能回踩

启动后锚定最大量成本区；实体新高且缩半，回踩成本区再试。

卖点 A

压力位减仓

靠近压力且上攻无力：先卖 1/3 或 1/2。

卖点 B

突破失败

放量突破又跌回：短线仓先走，站稳前不幻想。

卖点 V

放量滞涨/破位

放量不涨先离场；跌破最大量成本底则当笔逻辑失效。
