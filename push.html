每日做饭菜单

04 / Try it

马上试发做饭菜单

密钥已经在仓库里。做饭菜单用 Cook menu alert。

  1. 打开 Cook menu alert
  2. 点 Run workflow，分支选 main。
  3. 微信应收到标题「今日做饭菜单」。

股票提醒不构成投资建议。做饭菜单只是家常三餐建议。
