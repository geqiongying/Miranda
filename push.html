PushPlus

微信推送中心

通过 PushPlus 把收盘观察和每日晚饭菜单发到微信。一个负责提醒你复盘，一个负责解决晚饭吃什么。

01 / Why missing

为什么你会觉得推送不见了

PushPlus token 不能写在公开网页里，所以所有真实推送都放在 GitHub Actions 里运行。网页只保留说明和入口，具体发送由脚本完成。

当前包含两类推送：工作日收盘提醒、每天晚饭四人家常菜推荐。

03 / Dinner

每日晚饭菜单推送

每天北京时间 11:00 自动推送一套四人份家常晚饭菜单，脚本会在三菜一汤和四个菜之间自动轮换，并附上做饭顺序和买菜清单。

项目 说明
脚本 dinner_menu_push.py
工作流 Dinner menu push
时间 每天北京时间 11:00
本地预览 python3 dinner_menu_push.py --dry-run
菜单是家常快捷路线，默认按四人份设计；有时带汤，有时四个菜。如果家里临时多一个人，可以本地运行时加 --servings 5 预览。
04 / Setup

要真正发到微信，还差一步

把这个 PR 合并进 main 之后，到 GitHub 仓库加上 PushPlus 密钥。收盘提醒和晚饭菜单会复用同一个 token。

  1. 打开 PushPlus，复制你的 token。
  2. 打开 Miranda 仓库 → Settings → Secrets and variables → Actions。
  3. 新增 Repository secret，名称填 PUSHPLUS_TOKEN，值填 token。
  4. 如果要发到 PushPlus 群组，可再新增 PUSHPLUS_TOPIC。
  5. 到 Actions 里手动运行一次 Dinner menu push，确认微信能收到。
没有 token 时，定时任务会失败而不是悄悄空跑，GitHub Actions 会明确报错。

股票提醒只按规则发出观察信号，不构成投资建议。晚饭菜单仅作家常备餐参考，可按家人口味替换食材。
