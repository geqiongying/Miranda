01 / Why missing

为什么你会觉得推送不见了

之前做过 PushPlus 收盘提醒，但那份草稿一直没有合进正式站点。后来网站改成三入口学习站时，手机顶栏菜单也被直接藏掉了，所以「菜单」和「推送」看起来一起消失了。

这次已经把两件事一起补回来：手机可以重新打开菜单；推送页重新出现在导航里；收盘提醒脚本也回到仓库。

03 / Daily menu

每日观察菜单

这是第二条推送。工作日北京时间 08:20 从沪深主板 / 创业板 / 科创板里筛一份短线 5 只、中线 5 只的观察名单。它不是量能台或五哥台的教学买点，只是第一层观察菜单。

合并后到 Actions 里手动运行一次 Daily menu alert，微信就会马上收到今天的菜单。之后每个工作日早上自动再发。
04 / Setup

密钥已经配好

PUSHPLUS_TOKEN 已经在仓库里。收盘提醒用 Stock close alert；每日菜单用 Daily menu alert。两条都可以在 Actions 里手动试发。

  1. 打开 Actions：Daily menu alert。
  2. 点 Run workflow，分支选 main。
  3. 微信里应收到「Miranda 每日观察菜单」。
没有 token 时任务会明确失败，而不是悄悄空跑。

提醒只按规则发出观察信号，不构成投资建议。公开行情可能延迟，买卖前仍要打开券商软件核对。
