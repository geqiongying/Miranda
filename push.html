03 / Setup

要真正发到微信，还差一步

推送 token 不能写在公开网页里。把这个 PR 合并进 main 之后，再到 GitHub 仓库加上密钥。

  1. 打开 PushPlus，复制你的 token。
  2. 打开 Miranda 仓库 → Settings → Secrets and variables → Actions。
  3. 新增 Repository secret，名称填 PUSHPLUS_TOKEN，值填 token。
  4. 到 Actions 里手动运行一次 Stock close alert，确认微信能收到。
没有 token 时，定时任务会失败而不是悄悄空跑。合并本页后如果还没配密钥，GitHub Actions 会明确报错。

提醒只按规则发出观察信号，不构成投资建议。公开行情可能延迟，买卖前仍要打开券商软件核对。
